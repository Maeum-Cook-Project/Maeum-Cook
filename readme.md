# 🍳 Smart Kitchen IoT (스마트 키친 IoT)

`Smart Kitchen IoT`는 여러분의 주방을 더욱 스마트하고 편리하게 관리할 수 있도록 돕는 모바일 애플리케이션입니다.

주방의 핵심 기기인 인덕션, 싱크대, 환풍기를 원격으로 제어하고, 현재 보유한 식재료를 기반으로 AI 챗봇에게 레시피를 추천받아 요리의 전 과정을 스마트하게 경험해 보세요.

## 🚀 주요 기능

### 1. 스마트 주방 기기 제어

직관적인 인터페이스를 통해 주방 기기를 손쉽게 제어할 수 있습니다.

* **🔌 인덕션 (Induction)**
    * **전원 제어:** 원격으로 인덕션 전원을 켜고 끌 수 있습니다.
    * **온도 제어:** 요리에 맞는 최적의 온도를 3단계(1단계, 2단계, 3단계)로 조절합니다.
    * **타이머 설정:** 1분, 3분, 5분 단위로 간편하게 타이머를 설정하여 안전하고 정확한 요리를 돕습니다.
* **💧 싱크대 (Sink)**
    * **물 제어:** 원격으로 싱크대 물을 켜고 끌 수 있습니다.
* **🌬️ 환풍기 (Ventilation Hood)**
    * **전원 제어:** 요리 시 발생하는 냄새와 연기를 즉시 제거할 수 있도록 환풍기 전원을 제어합니다.



### 2. 지능형 레시피 및 식재료 관리

단순한 제어를 넘어, 스마트한 요리 경험을 제공합니다.

* **🥦 나의 식재료 관리**
    * 현재 보유한 식재료 목록을 관리합니다.
    * **간편한 추가/삭제:** 직관적인 UI를 통해 원하는 식재료를 빠르고 쉽게 추가하거나 삭제할 수 있습니다.
* **🤖 AI 챗봇 레시피 추천**
    * '나의 식재료'에 등록된 재료를 기반으로, AI 챗봇과의 대화를 통해 맞춤형 레시피를 추천받을 수 있습니다.
    * (예: "계란이랑 양파로 만들 수 있는 간단한 요리 추천해줘")
* **⭐ 레시피 즐겨찾기**
    * 챗봇에게 추천받은 레시피 중 마음에 드는 레시피를 '즐겨찾기'에 저장하여 언제든지 다시 확인할 수 있습니다.



## 📱 애플리케이션 화면 구성

*(이 섹션에는 실제 앱 디자인 스크린샷을 첨부하여 구성을 시각적으로 보여줄 수 있습니다.)*

1.  **홈 대시보드:** 연결된 모든 기기(인덕션, 싱크대, 환풍기)의 현재 상태를 한눈에 보여줍니다.
2.  **기기 제어 상세:** 각 기기를 선택하여 온도, 타이머 등 세부 옵션을 제어하는 화면입니다.
3.  **나의 식재료:** 식재료 목록을 확인하고, 간편하게 추가/삭제하는 화면입니다.
4.  **레시피 챗봇:** AI 챗봇과 대화하며 레시피를 추천받는 화면입니다.
5.  **즐겨찾기:** 저장된 레시피 목록을 확인하는 화면입니다.

## 💡 사용 방법

1.  앱을 실행하여 홈 IoT 허브를 연동합니다.
2.  **[나의 식재료]** 탭에서 현재 가지고 있는 식재료를 등록합니다.
3.  **[레시피 챗봇]** 탭에서 "오늘 뭐 먹지?" 또는 "있는 재료로 만들 수 있는 요리 알려줘"라고 질문합니다.
4.  추천받은 레시피를 **[즐겨찾기]**에 저장합니다.
5.  요리를 시작하며 **[홈 대시보드]** 또는 **[기기 제어]** 탭에서 인덕션의 온도와 타이머를 설정하고 환풍기를 작동시킵니다.
